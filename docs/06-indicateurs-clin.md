# 06 — مؤشرات CLIN الشهرية وبنية السجل

## التقرير الشهري الآلي (`rapportMensuel`)

يُولَّد فاتح كل شهر على بيانات الشهر المنقضي ويُرسل إلى المستلمين:

| المؤشر | تعريفه | قراءته |
|---|---|---|
| حجم البلاغات | عدد بلاغات الشهر | ارتفاعه في البداية علامة صحية (ثقافة تبليغ) لا العكس |
| % الحرج | نسبة خطورة ≥ 4 | يوجّه أولويات مخطط العمل |
| % الإغلاق | المغلقة ÷ مجموع بلاغات الشهر | مؤشر الانضباط الأول للوحدة |
| متوسط أجل الإغلاق | متوسط «Durée (h)» للمغلقة | زمن استجابة النظام الحقيقي |
| الحرج المفتوح الآن | عدد الحالات الحرجة غير المغلقة لحظة التقرير | يُفتتح به اجتماع CLIN |

## مؤشرات 2.1.0 (تُحسب من أعمدة السجل وورقة «Journal»)

| المؤشر | تعريفه | قراءته |
|---|---|---|
| معدل تأكيد الاستلام | البلاغات ذات «Pris en charge le» ÷ مجموع البلاغات | هل تُرى التنبيهات فعلًا وبسرعة؟ انخفاضه = مشكلة قناة لا أعوان |
| متوسط أجل التأكيد | متوسط (Pris en charge le − Date) للحرجة | زمن «أول عين بشرية» على الحالة الحرجة |
| % اكتمال حلقة التعلّم | حرجة مغلقة ذات «Action corrective» و«Vérification d'efficacité» ÷ مجموع الحرجة المغلقة | المؤشر النوعي الأول: هل نتعلم أم نطفئ فقط؟ |
| التجميعات المشبوهة | عدد تنبيهات «Regroupement suspecté» في الشهر (من «Journal») | ≥ 3 لنفس النوع والموقع في 7 أيام = مرشح لمراجعة مواضيعية في CLIN |
| المواقع الصامتة | مواقع بلا بلاغ منذ `SILENCE_SEMAINES` أسبوعًا (تنبيه الاثنين) | الصمت الطويل = اشتباه ضعف تبليغ، يُعالج بالدعم لا باللوم |
| معدل التحقق من الفعالية | حرجة ذات تحقق ÷ حرجة استحقت التحقق (مغلقة منذ ≥ 7 أيام) | انضباط إغلاق حلقة التعلم زمنيًا |

## أعمدة سجل «Suivi UPCI» (النموذج في `registre/modele-registre.csv`)

| العمود | المعنى |
|---|---|
| Date | تاريخ/وقت تسجيل البلاغ |
| Numéro | الرقم التسلسلي UPCI-AAAA-NNNN |
| Type | Signalement / Clôture |
| Polyclinique | موقع الحادث |
| Service | المصلحة أو المكان الدقيق |
| Gravité | من 1 إلى 5 (العتبة الحرجة = 4) |
| Délai demandé | الأجل الذي طلبه المُبلّغ |
| Mesures | ما فُعل فورًا عند الاكتشاف |
| Statut | Ouvert / Clôturé |
| Intervention | ما أنجزه التدخل عند الإغلاق |
| Délai réel | الأجل الفعلي المستغرق |
| Date clôture | تاريخ الإغلاق |
| Durée (h) | مدة المعالجة بالساعات (تُحسب آليًا) |
| Relance 1h | ختم التذكير الآلي للحرج (إن حدث) |
| Escalade 4h | ختم التصعيد الآلي (إن حدث) |
| Email déclarant | بريد المُبلّغ (داخلي — لإشعار الإغلاق فقط) |
| Action corrective | ما تغيّر لمنع التكرار (حرجة) — V5 |
| Vérification d'efficacité | نتيجة التحقق اللاحق من زوال المشكل (حرجة) — V5 |
| Pris en charge le | وقت تأكيد الاستلام بزرّ Telegram — V5 |
| Accusé par | اسم من أكّد الاستلام — V5 |
| Relance accusé | ختم تذكير «غير مُستلم» (إن حدث) — V5 |
| Msg Telegram | مراجع رسائل التنبيه (لتحديثها عند التأكيد) — V5 |
| Relance vérification | ختم تذكير التحقق من الفعالية (إن حدث) — V5 |

وورقة ثانية **«Journal»** (V5) هي سجلّ التدقيق: Horodatage، Numéro، Acteur،
Action، Détail — تُكتب بالإلحاق فقط ولا تُعدَّل: إنشاء، تأكيد، تذكير، تصعيد،
إغلاق، تحقق، إعادة فتح، تجميع، صمت، سلامة النظام، نشرة.

## استعمال المؤشرات في مخطط عمل الوحدة

- نوع الحوادث الأكثر تكرارًا = موضوع أول إجراء وقائي/تكويني في الشهر الموالي.
- موقع (عيادة/مصلحة) يتصدّر التكرار = زيارة مرافقة ودعم، لا لوم.
- أجل إغلاق يتدهور = مشكلة إمكانيات (مستهلكات/صيانة) تُرفع للإدارة بالأرقام.
